# Examify — Online Examination System

A complete responsive Online Examination System built with HTML, CSS and vanilla JavaScript.

## Features
- Attractive responsive homepage
- Multiple exam/quiz cards
- Category filters
- MCQ examination interface
- Question navigation/palette
- Countdown timer with auto-submit
- Previous/Next navigation
- Instant result calculation
- Correct, wrong and skipped counts
- Percentage and pass/fail summary
- Answer review after submission
- LocalStorage-based exam history
- Dark mode
- Mobile/tablet/desktop responsive design
- No backend required

## How to Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Select an exam and click **Start Exam**.
4. Answer questions and submit.
5. Results and history are saved in browser LocalStorage.

Edit `js/data.js` to add or change exams, categories, questions, options, answers, duration and difficulty.
